To move all **negative numbers to the left** and **positive numbers to the right** of an array in JavaScript, while **maintaining their original order**, you can use the following approach:

### ✅ Solution (Preserve Order):

```javascript
let arr = [23, -7, 12, -10, -11, 40, 60];

let negatives = arr.filter(num => num < 0);
let positives = arr.filter(num => num >= 0);

let result = [...negatives, ...positives];

console.log(result); // Output: [ -7, -10, -11, 23, 12, 40, 60 ]
```

### 🔄 Alternate (If order doesn't matter):

If you **don't need to preserve the order**, you can do it in-place:

```javascript
let arr = [23, -7, 12, -10, -11, 40, 60];

let left = 0, right = arr.length - 1;

while (left < right) {
  if (arr[left] < 0) {
    left++;
  } else if (arr[right] >= 0) {
    right--;
  } else {
    // swap
    [arr[left], arr[right]] = [arr[right], arr[left]];
    left++;
    right--;
  }
}

console.log(arr);
```
