| Hook                   | Main purpose                             |
| ---------------------- | ---------------------------------------- |
| `useState`             | Store state                              |
| `useEffect`            | Side effects                             |
| `useContext`           | Read shared context                      |
| `useRef`               | Persistent mutable value / DOM reference |
| `useMemo`              | Cache a calculation                      |
| `useCallback`          | Cache a function                         |
| `useReducer`           | Complex state logic                      |
| `useLayoutEffect`      | DOM/layout work before paint             |
| `useImperativeHandle`  | Customize a ref API                      |
| `useId`                | Generate unique IDs                      |
| `useTransition`        | Mark updates as non-urgent               |
| `useDeferredValue`     | Defer a value                            |
| `useSyncExternalStore` | Subscribe to external stores             |
| `useInsertionEffect`   | CSS-in-JS style insertion                |
| `useEffectEvent`       | Non-reactive logic used from Effects     |
| Custom Hooks           | Reuse stateful logic                     |


What are React Hooks?

Hooks are functions that let functional React components use features such as state, lifecycle behavior, context, refs, and performance optimization.
