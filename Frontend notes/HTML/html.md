what is block element and inline element
block element 
Take up full width available by default (stretch across the container).
Start on a new line and stack vertically.
Can have width, height, margin, and padding all respected.
Examples: <div>, <p>, <h1> - <h6>, <ul>, <li>, <section>, <header>

inline element
Only take up as much width as their content.
Do not start on a new line; they flow horizontally next to each other.
You cannot set width or height directly.
Padding and margin on left and right work; top and bottom margin/padding may behave inconsistently.
Examples: <span>, <a>, <strong>, <em>, <img>

inline block
Elements with display: inline-block flow inline (horizontally like inline elements) — so they don’t start on a new line.
But unlike inline elements, they can have width, height, margin, and padding — like block elements.
So you get the best of both worlds: they sit next to each other horizontally, but behave like blocks in terms of box model.

### 🔹 1. **New Semantic Elements**

These elements give more meaning to the structure of web pages:

* `<header>` – Defines a header for a document or section.
* `<footer>` – Defines a footer for a document or section.
* `<nav>` – Defines a section for navigation links.
* `<article>` – Defines self-contained content.
* `<section>` – Defines a thematic grouping of content.
* `<aside>` – Defines content indirectly related to the main content.
* `<main>` – Represents the main content of a document.

---

### 🔹 2. **New Form Controls**

Improved form elements for better input handling:

* `<input type="email">`
* `<input type="url">`
* `<input type="date">`
* `<input type="range">`
* `<input type="search">`
* `<input type="color">`
* `<datalist>` – Provides a list of predefined options.
* `<output>` – Displays the result of a calculation.

---

### 🔹 3. **Audio and Video Support**

Native support for media without plugins:

* `<audio>` – Embeds sound/audio content.
* `<video>` – Embeds video content.
* `<source>` – Specifies media resources.
* `<track>` – Adds subtitles or captions.

---

### 🔹 4. **Canvas Element**

* `<canvas>` – A drawable region in HTML for rendering graphics via JavaScript (used for games, charts, etc.).

---

### 🔹 5. **SVG Support**

* Scalable Vector Graphics (`<svg>`) can be used directly in HTML.

---

### 🔹 6. **Geolocation API**

* Allows websites to get the geographical location of a user (with permission).

---

### 🔹 7. **Local Storage & Session Storage**

For storing data on the client side:

* `localStorage` – Stores data with no expiration date.
* `sessionStorage` – Stores data for one session.

---

### 🔹 8. **Web Workers**

* Allows JavaScript to run in the background (multithreading) without blocking the UI.

---

### 🔹 9. **Drag and Drop API**

* Built-in support for dragging and dropping elements on the page.

---

### 🔹 10. **Improved Accessibility and Doctype**

* Simplified doctype: `<!DOCTYPE html>`
* Better support for screen readers and accessibility tools.
