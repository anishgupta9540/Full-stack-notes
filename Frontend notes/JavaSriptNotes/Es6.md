Here is a **complete & structured list of ALL major ES6 (ECMAScript 2015) features in JavaScript**.
This is the **most commonly accepted full list** used for **interviews, React, and modern JS development**.

---

# ✅ **ALL ES6 FEATURES (FULL LIST)**

---

## 🔹 **1. Variable Declarations**

* `let`
* `const`
* Block scope

---

## 🔹 **2. Arrow Functions**

* Short function syntax
* Lexical `this` binding
* No `arguments` object

---

## 🔹 **3. Template Literals**

* Backticks `` ` ``
* `${}` interpolation
* Multiline strings

---

## 🔹 **4. Default Parameters**

* Function parameters with default values

---

## 🔹 **5. Destructuring Assignment**

* Array destructuring
* Object destructuring
* Nested destructuring

---

## 🔹 **6. Spread Operator (`...`)**

* Expand arrays
* Expand objects
* Function arguments

---

## 🔹 **7. Rest Parameters (`...`)**

* Collect remaining arguments into array

---

## 🔹 **8. Enhanced Object Literals**

* Property shorthand
* Method shorthand
* Computed property names

---

## 🔹 **9. Classes**

* `class` keyword
* `constructor()`
* Methods
* `extends`
* `super()`
* Static methods

---

## 🔹 **10. Modules**

* `export`
* `export default`
* `import`

---

## 🔹 **11. Promises**

* `Promise`
* `.then()`
* `.catch()`
* `.finally()`

---

## 🔹 **12. Iterators**

* `Symbol.iterator`
* Custom iterators

---

## 🔹 **13. Generators**

* `function*`
* `yield`
* `next()`

---

## 🔹 **14. for...of Loop**

* Iterating over iterable objects

---

## 🔹 **15. Map**

* `new Map()`
* `set()`, `get()`, `has()`, `delete()`

---

## 🔹 **16. Set**

* `new Set()`
* Unique values
* `add()`, `has()`, `delete()`

---

## 🔹 **17. WeakMap**

* Keys must be objects
* Garbage collected

---

## 🔹 **18. WeakSet**

* Stores objects only
* Weak references

---

## 🔹 **19. Symbols**

* `Symbol()`
* Unique identifiers
* Well-known symbols

---

## 🔹 **20. Binary & Octal Literals**

```js
0b1010 // binary
0o12   // octal
```

---

## 🔹 **21. New Math Methods**

* `Math.trunc()`
* `Math.sign()`
* `Math.cbrt()`
* `Math.clz32()`

---

## 🔹 **22. New Number Methods**

* `Number.isNaN()`
* `Number.isInteger()`
* `Number.isFinite()`

---

## 🔹 **23. New String Methods**

* `includes()`
* `startsWith()`
* `endsWith()`
* `repeat()`

---

## 🔹 **24. New Array Methods**

* `find()`
* `findIndex()`
* `fill()`
* `copyWithin()`
* `from()`
* `of()`

---

## 🔹 **25. Object Methods**

* `Object.assign()`
* `Object.is()`
* `Object.setPrototypeOf()`
* `Object.getPrototypeOf()`

---

## 🔹 **26. Tail Call Optimization (TCO)**

* Optimized recursive calls *(conceptual)*

---

## 🔹 **27. Proxy**

* `new Proxy(target, handler)`
* Intercept operations

---

## 🔹 **28. Reflect API**

* `Reflect.get()`
* `Reflect.set()`
* `Reflect.apply()`

---

## 🔹 **29. Unicode Enhancements**

* Better Unicode support
* `\u{1F600}` syntax

---

## 🔹 **30. Computed Property Names**

```js
const prop = "age";
const user = {
  [prop]: 25
};
```

---

# 📌 **ES6 = ECMAScript 2015**

> Everything above was introduced **together** in ES6.
